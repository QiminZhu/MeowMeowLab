# Feedback sound assets

Upload the two feedback sounds to this directory using these exact filenames:

```text
public/sounds/feedback/question-correct.ogg
public/sounds/feedback/end-of-task.ogg
```

- `question-correct.ogg` plays after a correct iteration.
- `end-of-task.ogg` plays after the final iteration completes the full task.

OGG files are served from `/sounds/feedback/` by Vite.
